# predylogic

--8<-- "README.md:badges"

> 一个可嵌入、可组合、schema 驱动的谓词逻辑引擎。

predylogic 把布尔谓词当作**可编译的 AST** 来处理,而不是逐次解释:

- **可组合**:用 `&` / `|` / `~` 以及 `all_of` / `any_of` 把原子规则拼成谓词树。
- **schema 驱动**:序列化的规则清单(Pydantic)编译为谓词树,支持热更新与 tombstone。
- **Trace**:`trace=True` 时返回一棵求值结果树——这是它区别于其他规则引擎的核心能力。
- **零开销快路径**:首次调用时把谓词树编译成 Python 字节码并缓存,运行期是原生 opcode。
