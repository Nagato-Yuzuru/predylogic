# 组合与性能

!!! note "大纲草稿"

_本页目标:讲清几种组合方式的取舍,以及性能从哪来。_

## 两种组合写法

_待写:`&` `|` `~` 运算符重载 vs `all_of` / `any_of`;前者顺手,后者对大量同构组合更快(扁平 N-ary)。_

## N-ary 展平

_待写:`all_of([a, all_of([b, c])])` 在编译期展平成单个 N-ary,不留二叉嵌套(monoid 结合律)。_

## 快路径:编译到 bytecode

_待写:首次调用把谓词树编译成 Python 字节码并缓存,之后是原生 opcode;不要在快路径上加开销。_
_深入原理见 [ADR 002](../design/adr/002_AST_compiler_optimization.md)。_

## 什么时候该关心性能

_待写:大多数场景不必操心;给出何时该用 `all_of` / `any_of`、何时无所谓的判断标准。_
